# Анализ модели для БАЗИС-Мебельщик

Быстрая замена штатного «Анализа модели»: пересечения деталей, отверстия и крепёж, кромки, позиции, сверка с
каталогом Вияра, петли против ручек и TIP-ON. Результаты — в отдельном окне, щелчок по замечанию выделяет
объект в модели.

## Как поставить

1. Нажмите **Code → Download ZIP** и распакуйте.
2. Папку **«Анализ модели»** скопируйте в папку скриптов БАЗИС.
3. Запустите в БАЗИС `Анализ модели.js`. Скрипт покажет код компьютера — отправьте его автору и получите
   файл лицензии `license.lic`.

Подробности — в файле [ПРОЧТИ_МЕНЯ.md](Анализ%20модели/ПРОЧТИ_МЕНЯ.md) внутри папки.

## Обновления

Ставить заново не нужно: в окне скрипта на вкладке «О программе» есть кнопка «Проверить обновления».
Окно берёт новую сборку из этого репозитория и принимает её только с подписью автора.

Здесь лежит только готовая сборка. Скрипт анализа зашифрован и без лицензии не запускается.
